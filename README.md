# Times Tables Team

Build "Times Table Quiz", a tiny web app for kids aged 7 to 10 to practise one multiplication table at a time.

What it must do:
1. Home: pick a table from 1 to 10. Each table shows its best score.
2. Quiz: 10 questions from that table, a big on-screen number keypad, instant friendly feedback (show the right answer when wrong), then "You got 8 out of 10!" with a Play again button. The best score per table is saved on the device.

Rules: phone-first, no accounts, no backend, no tracking. Deploy to GitHub Pages and give me the live link.

Keep it tiny: ship as soon as these two screens work. No extra features. Don't wait for me with questions; make reasonable decisions yourself. I will look at it when it is live.
